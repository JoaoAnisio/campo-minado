# 🧨 Campo Minado em Java (Swing)

Projeto de **Campo Minado** desenvolvido em **Java**, utilizando a biblioteca **Swing** para criação da interface gráfica.  
O objetivo do projeto é aplicar conceitos de **Programação Orientada a Objetos**, **eventos**, **lógica de jogo** e **interfaces gráficas**.

---

## 🎯 Objetivo do Projeto

- Praticar lógica de programação
- Aplicar conceitos de **POO em Java**
- Trabalhar com **interfaces gráficas (Swing)**
- Simular o clássico jogo Campo Minado

---

## 🕹️ Funcionalidades

- Interface gráfica interativa
- Geração automática do campo com minas
- Cálculo de minas adjacentes
- Abertura de células com clique
- Finalização do jogo ao clicar em uma mina
- Atualização visual em tempo real

---

## 🛠️ Tecnologias Utilizadas

- **Java**
- **Java Swing**
- **Eclipse IDE** (estrutura compatível)
- Programação Orientada a Objetos (POO)
